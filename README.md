# Portfolio personal — Joaquin Dominguez

Portfolio web personal desarrollado como proyecto escolar para presentar mi perfil, mis intereses relacionados con la informática y algunos trabajos realizados durante mi aprendizaje.

## ¿Qué contiene la página?

La página está organizada en distintas secciones a las que se puede acceder desde el menú de navegación:

- **Inicio:** presenta el nombre, una breve descripción personal y accesos directos a los proyectos y a la sección «Sobre mí».
- **Sobre mí:** cuenta quién soy, qué temas me interesan y cómo me gusta aprender y trabajar.
- **Conocimientos:** muestra las áreas que estoy aprendiendo o explorando, como desarrollo web (HTML, CSS y JavaScript), creación de videojuegos y modelado 3D con Blender.
- **Proyectos:** presenta trabajos y propuestas, junto con una descripción, mi participación y las herramientas relacionadas. En esta versión se incluyen ApunteQR, una calculadora de promedios escolares en C++ y un simulador de red escolar.
- **Educación:** incluye información general sobre mi formación secundaria.
- **Contacto:** contiene accesos para comunicarse por correo electrónico, GitHub y LinkedIn. Los enlaces de ejemplo deben reemplazarse por los datos reales antes de publicar el sitio.

## ¿Cómo funciona?

El sitio está construido con tres tecnologías principales:

- **HTML5 (`index.html`):** define la estructura y el contenido de cada sección.
- **CSS3 (`css/estilos.css`):** controla los colores, las fuentes, la distribución de los elementos, las animaciones y la adaptación a distintos tamaños de pantalla.
- **JavaScript (`js/script.js`):** agrega la interacción del menú de navegación en dispositivos móviles, permitiendo abrirlo y cerrarlo.

El menú utiliza enlaces internos que llevan a cada sección de la misma página. Los botones principales también permiten desplazarse a partes específicas, por ejemplo, desde el inicio hasta los proyectos o el contacto.

El diseño es adaptable (*responsive*), por lo que reorganiza sus elementos para que el contenido pueda visualizarse tanto en computadoras como en celulares. Las fuentes Poppins e Inter se cargan desde Google Fonts, por lo que se necesita conexión a Internet para mostrarlas tal como fueron diseñadas.

## Estructura de archivos

```text
portfolio_joaquin/
├── index.html          # Estructura y contenido de la página
├── css/
│   └── estilos.css     # Estilos, colores y diseño responsive
├── js/
│   └── script.js      # Funcionamiento del menú móvil
├── assets/
│   └── img/            # Carpeta para imágenes y recursos gráficos
├── bitacora_ia.md      # Registro del uso de herramientas de IA
└── README.md           # Información e instrucciones del proyecto
```

## ¿Cómo abrir la página?

1. Descargá o descomprimí la carpeta del proyecto.
2. Abrí la carpeta `portfolio_joaquin`.
3. Hacé doble clic en `index.html` o abrilo desde un navegador web.
4. Para modificar el proyecto, abrí la carpeta completa con un editor de código, por ejemplo Visual Studio Code.
